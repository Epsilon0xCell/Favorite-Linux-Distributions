Garuda Linux KDE and Pop!_OS Cosmic Desktop, and the pick I get when I put them together.

Plate 0. Banner from this repo. See also logo.png in the repo root.

I keep this list short on purpose. The two setups in this guide are the ones I like most, one with the KDE desktop and one with the Cosmic desktop.

My pick at the end is what I get when I put those two choices together: Garuda, but with Cosmic instead of KDE. That is the whole list. I did not pad it with runners up I do not actually favour.

This repo is a README and these picks. There is no code in it, and this guide does not pretend otherwise.
